# Number-guessing-game

A simple number guessing game written in c++

## Description

The program randomly generates a number between 1 and 100.
The player has to guess the number, and the program gives hints
by telling the player whether the guess is too low or too high.

The game also counts the number of attempts needed to find the
correct number.

## Features

- Random number generation
- User input
- Hints for each guess
- Attempt counter
- Invalid input handling

## How to play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints:
   - `Too low!` means the secret number is higher.
   - `Too high!` means the secret number is lower.
4. Continue until you find the correct number.

## Language

- C++
